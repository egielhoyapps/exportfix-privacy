Local release 1.0.1

This version makes no network requests, includes no analytics, and has no payment or licensing integration. Imported file contents live in memory while the workspace is open. Saved recipes are stored in this browser profile; recipes contain column names and transformation settings, not source records.

Downloaded exports and recipe backups remain wherever your browser saves them. Removing the extension or clearing its storage may erase saved recipes. Export backups first.

Limits and behavior

Maximum input: 10 MiB, 100,000 data records, 200 columns. First record must have unique, non-empty headers. Supported delimiters: comma, semicolon, tab, pipe. Encodings: UTF-8, Windows-1252, UTF-16 LE/BE. Excel .xlsx workbooks are supported with worksheet selection; legacy .xls, macro-enabled and encrypted workbooks are not supported. Expanded workbook archive limit: 64 MiB. Row 1 must contain headers; merged cells are rejected. Hidden rows are included. Formulas use saved cached results and are never recalculated; missing results and Excel errors block import.

Dates accept numeric day, month and four-digit year separated by matching slash, dot, or hyphen separators. Timestamps, month names, and two-digit years are not converted. Invalid dates block export until resolved or date conversion is disabled. Recipe schemas must match exactly; source column order may differ.

Duplicate comparison uses selected source columns after transformations and keeps the first record. Comparison is case-sensitive. Blank records are removed only when all original fields are whitespace or empty. Date validation covers all non-empty input records, even duplicates.

The preview displays up to 50 records and truncates long cell text visually. Exports include full processed data. Values are handled as strings. CSV text and Excel text cells preserve zeros and large integer digits. Excel numeric cells may already have lost precision or leading zeros; these cannot be recovered. Simple zero-padding formats are preserved. Spreadsheet programs may still automatically interpret a CSV when opening it: use their text-import feature for ID columns.

For CSV and TSV, formula protection adds an apostrophe to text beginning with a spreadsheet formula marker, including negative numbers. Review output for your destination. It is a mitigation, not a guarantee across every spreadsheet application. UTF-8 BOM is optional.

Native Excel calendar dates are read using the workbook date system and normalized to ISO text. Date-time values retain their time component; date-only conversion rejects timestamps. Ambiguous text dates require confirmation when choosing day-first or month-first conversion. Mixed text date orders must be corrected in the source. XLSX exports default to text. Optional column types export selected columns as numeric or date cells for calculations, with IDs kept as text. Invalid typed values block XLSX export. JSON exports contain ordered columns and rows arrays of strings.
